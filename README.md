Magnetic Exchange Coupling from Wannier Hamiltonians with Spin–Orbit Coupling

Overview

This project provides a Python implementation for calculating magnetic exchange coupling parameters and noncollinear exchange tensors from a spinor Wannier Hamiltonian derived from first-principles electronic structure calculations.

The implementation explicitly accounts for spin–orbit coupling (SOC) using a spinor representation of the Wannier Hamiltonian and evaluates magnetic exchange interactions with a Green's function-based approach.

To improve the numerical accuracy of Brillouin-zone integrations, the code uses an optimized tetrahedron integration method implemented in the accompanying `tetra.py` module.

The program lets users define magnetic sites, Wannier orbital subspaces, k-point meshes, and energy integration parameters, enabling flexible studies of magnetic interactions in materials with noncollinear magnetism and strong spin–orbit coupling.

Key Features

Spin–orbit coupling: Supports spinor Wannier Hamiltonians with explicit SOC.
Noncollinear magnetic interactions: Calculates exchange tensors using a Green's function formulation.
Optimized tetrahedron integration: Uses tetrahedron-based numerical integration to improve the accuracy of Brillouin-zone integration.
Flexible magnetic-site selection: Lets users assign Wannier functions to individual magnetic sites.
Customizable computational parameters: Lets users define k-point meshes, energy integration ranges, Fermi energies, and temperatures.
Wannier90 compatibility: Loads the real-space Hamiltonian from the standard `wannier90_hr.dat` file.
Crystal structure support: Extracts structural information from the POSCAR file.

Magnetic-Site and Wannier Function Selection

The --site-wfs argument specifies which Wannier functions belong to each magnetic site.

For example:

--site-wfs "0,1" "5,6,7"

This defines two magnetic sites:

Site 1: Wannier functions 0 and 1.
Site 2: Wannier functions 5, 6, and 7.
Additional magnetic sites can be included:

--site-wfs "0,1" "5,6" "10,11"

The number of Wannier functions assigned to a site determines the size of its orbital subspace and the corresponding site-resolved matrix blocks.

However, the total Hamiltonian dimension is determined by the number of Wannier functions stored in wannier90_hr.dat.

For spinor Hamiltonians, the orbital indices must match the exact ordering of the spinor Wannier basis.

Computational Methodology

The calculation relies on three main components.

1. Spinor Wannier Hamiltonian

The real-space Wannier Hamiltonian is read from wannier90_hr.dat. The reciprocal-space Hamiltonian is reconstructed using a Fourier transformation:

H(\mathbf{k}) =
\sum_{\mathbf{R}} H(\mathbf{R})
e^{i\mathbf{k}\cdot\mathbf{R}}.

Here, (H(\mathbf{R})) represents the real-space hopping matrices, including spin-dependent terms originating from spin–orbit coupling.

2. Green's Function Formalism

The electronic Green's function is constructed from the Wannier Hamiltonian:

G(\mathbf{k},z)=
\left[zI-H(\mathbf{k})\right]^{-1},

where (z) is the complex energy and (I) is the identity matrix.

The Green's function provides the electronic response data needed to evaluate magnetic exchange interactions between selected magnetic sites.

The spinor representation allows SOC-induced anisotropic contributions to the magnetic exchange tensor to be treated.

3. Optimized Tetrahedron Integration

Accurate integration over the Brillouin zone is essential for evaluating exchange interactions, especially in systems with complex electronic structures.

The implementation uses the optimized tetrahedron integration method in `tetra.py` to evaluate k-dependent quantities more accurately.

Integration accuracy can be systematically assessed by varying the k-point mesh and energy discretization parameters.

Numerical Convergence

For reliable results, users are encouraged to perform convergence tests with respect to:

k-point sampling: Increase the k-point mesh to test Brillouin-zone integration convergence.
Energy integration range: Ensure that the selected energy window adequately covers the electronic states relevant to the calculation.
Energy resolution: Increase --ne to examine numerical stability.
Wannierization quality: Verify that the spinor Wannier Hamiltonian accurately reproduces the relevant first-principles band structure.
Magnetic-site orbital selection: Ensure the correct assignment of spinor Wannier functions to each magnetic site.
Exchange interactions can be sensitive to numerical sampling and the choice of magnetic orbital subspaces. We therefore strongly recommend convergence tests before interpreting the calculated values.

Applications

This code is designed for computational studies of:

Magnetic exchange interactions in crystalline materials.
Noncollinear magnetic systems.
Spin–orbit-coupled magnetic materials.
Anisotropic magnetic exchange interactions.
First-principles studies of magnetic interactions using Wannier tight-binding Hamiltonians.

Notes

·      The Wannier Hamiltonian and POSCAR structure must represent the same crystal system and use compatible lattice conventions.

·      The Wannier function indices must match the ordering in the input Hamiltonian.

·      Specify the Fermi energy relative to the Wannier Hamiltonian’s energy reference.

·      Ensure the `tetra.py` module is available to the main Python script.

·      The example command assumes energy parameters are in electronvolts and temperature is in Kelvin.

·      Check the sign convention, tensor indexing, and units of the computed exchange parameters against the implementation’s definitions.
